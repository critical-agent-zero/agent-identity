# Internal planning documents

Everything under this directory is historical internal planning and spec
material — implementation plans and design documents written while the
project was being built. These are **not product documentation**: they may
be stale, and they reference internal tooling, machine-specific setups, and
paths that predate the current repository layout (for example
`docs/superpowers/...`, this directory's former name). They are kept for
provenance — to show why the system is shaped the way it is.

For adopter-facing documentation, see the [root README](../../README.md)
and [docs/forge-access.md](../forge-access.md).
